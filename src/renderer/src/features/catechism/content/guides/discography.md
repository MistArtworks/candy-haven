# DISCOGRAPHY

## What you have put out

The ARCHIVE answers _what have I made_. This answers _what have I put out_.

They are different questions, and the difference matters: a discography
includes a back catalogue, a label master and somebody else's remix — none of
which has an Ableton project on this machine. So an entry **stands alone**,
and links to a project only when there is one.

**Raise a release** opens a dialog — the title and the kind are required and
nothing else is. A single or a remix arrives with its one track already on it,
because a single _is_ a recording; the longer kinds start empty.

## Kind, and status

**Kind** is what it is — single, EP, album, compilation, remix.

**Status** is how public it is, and there are two: **scheduled** or
**released**. Either it is out or it is not.

Leaving the date empty on a scheduled entry is what says "going out, when is
not fixed yet".

Status is not a project's stage. A stage says how finished the work is; a
status says whether it is out. A track sits at TRACK READY for months while a
label schedules it, and neither figure is wrong.

Marking a release RELEASED does move the projects behind its tracks to the
RELEASED stage in the ARCHIVE. Moving it back returns them.

> RELEASED is refused without a date. The catalogue sorts by date, and an
> entry claiming to be out with no date files itself under every idea.

## The running order, and the link

A release owns its tracklist. Each track can name the ARCHIVE project behind
it, and the picker offers **finished work only** — projects at TRACK READY or
later. If something is missing from it, move it to TRACK READY in the ARCHIVE.

A track with no project is ordinary: a back catalogue has none.

## Which file shipped

Once a track has a project, **PICK MASTER** lists that project's own bounces and
records which one went out.

Nothing moves. The release stores the path to the file where it already sits,
so clicking it opens the folder it lives in — and the project's dossier reports
the same thing from the other end, under RECORD.

> This used to be set in the ARCHIVE, and it moved the file into
> `Release Mastered Tracks`. That took the audio away from the session that made
> it, which is the opposite of being able to find the source.

## Credits

**Main artist** and **featuring** are how the release is titled.

The **credits** list underneath is the liner notes — a line per role, naming who
produced, sang, wrote, mixed or drew it. All optional; most singles have none.

## Where it went

Label, catalogue number, UPC, the ℗ and © lines, and a link for every place
it is streaming. ISRCs sit on the **track**, because that is what an ISRC
identifies — one album, one UPC, eleven ISRCs.

Cover art and canvas are copied into the archive, so the originals can be
moved or deleted afterwards.
