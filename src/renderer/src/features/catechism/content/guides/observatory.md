# OBSERVATORY

## One server, many sources

![observatory-01-catalogue.png](observatory-01-catalogue.png)

This page is a catalogue rather than a feature. Every overlay is served from one
local address on its own path, and each is a separate Browser source in OBS.

The status in the masthead tells you whether the server is up and how many
sources are currently attached to it.

## Adding one to OBS

![observatory-02-card.png](observatory-02-card.png)

1. Copy the address from the overlay's card.
2. In OBS, add a **Browser** source.
3. Paste the URL, and set the width and height the card quotes.
4. Leave "Shutdown source when not visible" off, so state survives a scene change.

> Cards marked **panel** are meant to sit over a scene and want the transparent
> address. Cards marked **full** are their own scene.

## The kit

- **THE MUSTER** — an open call. Chat files entries against a question.
- **RESONANCE SELECTION** — a weighted draw on a rotating ring.
- **THE CONCORD** — chat votes on a ballot; a deadlock is settled by casting lots.
- **NOW TRANSMITTING** — live Spotify playback, in four presentations.
- **INTERVAL** — a countdown with a grace period, for breaks.
- **CONVENING** — a stream-opening countdown that resolves to NOW.
- **THE CHORUS** — chat as an institutional register. Pasted into Streamlabs
  rather than served from here.
