# Glossary

This console names things in its own register. Most of the words mean exactly
what a plainer word would mean; a few carry a distinction worth knowing. Both
are listed, because the second kind is impossible to spot without the first.

## The console

**Department** — a section of the console, reached from the rail. Ten of them,
grouped into four divisions.

**Division** — the grouping a department is filed under: COMMAND, PRODUCTION,
BROADCAST, OVERSIGHT. It tells you what kind of question the departments inside
it answer.

**Reserved** — a department that is routed and specified but not yet built. Its
page lists what it will do when commissioned. INTERFACE is the only one.

**Masthead** — the header every page opens with: number, label, purpose, rule,
epigraph.

**Epigraph** — the flavour line under a masthead's rule. Drawn from the world
brief. It is never load-bearing; nothing depends on reading it.

**Panel** — the standard container. Square corners, hairline border, numbered
label.

**Focal** — the one crimson-accented element a view is allowed. At most one per
page, by rule.

**Readout** — a figure set in the monospace face. Numbers that should not shift
width as they change.

## THE ARCHIVE

**The Archive** — both the department and the private database underneath it. In
REGULATION, "archive" settings are about the database; in the rail, ARCHIVE is
the department.

**Lens** — what is in scope. STACKS, INTAKE, VOLUMES, ALL, BIN.

**View** — how whatever is in scope is drawn. ICONS, LIST, BOARD.

**The Stacks** — the filing tree you build, and the shelving in it. Named for the
shelving rather than for any one thing on it.

**Shelf** — a folder that holds projects. A genre or an artist, never a category.

**Category** — two different things, and this is the one genuine collision:

1. a **folder kind** at the top of the filing tree, which holds genres and artists;
2. a **project property** saying what kind of release it is (SINGLE, EP, ALBUM…).

Context separates them: a category you click into is a folder, a category on a
dossier is a property.

**Volume** — an album, EP or compilation as an actual collection, with tracks
bound into it in order. Distinct from a project's _category_, which is only a
label.

**Project** — one piece of work: a real directory holding a Live set, its
samples, bounces and backups. The unit everything in this department is about.

**Set** — the Ableton `.als` file itself. A project can hold several; one is
primary.

**Dossier** — the full record for one project, opened as an overlay.

**Stage** — where a project has got to in the pipeline. IDEA through TRACK
READY, plus SHELVED off to the side.

**Pipeline** — the six stages in a line. SHELVED is off-pipeline.

**Intake** — bringing work that is already on disk into the register. Named for
what an archive does continually, rather than "migration", which is something a
database does once.

**Not indexed** — a directory the register has never seen. It cannot be filed
until a scan has indexed it.

**Filing root** — the directory your shelves live in. Set in REGULATION; nothing
in the department works without it.

**Satellite root** — a further directory the scan also walks.

**Marked** — picked out for a bulk move, by tick or by Ctrl/Shift-click. Distinct
from **selected**, which is just where the cursor is.

**Final mix / final master** — the specific files that ship. Naming them is what
lets a project reach TRACK READY.

**Release Mastered Tracks** — the directory a final master moves into when
chosen.

**The Bin** — deleted projects, in a real directory, kept until emptied.

## THE OBSERVATORY

**Overlay** — one browser source this console serves and drives.

**Browser source** — OBS's term for a web page composited into a scene. Every
overlay is one.

**Canvas** — the width and height an overlay is designed for, quoted on its card.

**Full / panel** — whether an overlay is its own scene, or furniture composited
over one.

**Address** — the URL an overlay answers on. Some overlays answer on more than
one, each pinning a different presentation of the same state.

**Citizen** — a viewer in chat. Used wherever chat participation is counted.

**The Muster** — an open call. Chat files entries against a question.

**Roll** — the numbered list of entries a muster collects.

**Resonance Selection** — the weighted draw. Also called _the rite_.

**Petition** — one entry in a draw.

**Weight** — how much of the field a petition occupies. 1 to 999.

**Mechanism** — how a draw is presented: RESONANCE RING, THE PROCESSION, THE
DESCENT.

**Elimination** — withdrawing each winner from the pool, so a series of draws
walks the field.

**The Concord** — the vote. Also called _the chamber_ while it sits.

**Ballot** — the numbered options chat votes between.

**The Casting** — what settles a deadlocked Concord. Equal lots, one taken.

**Now Transmitting** — live Spotify playback.

**The Chorus** — chat as an institutional register. Pasted into Streamlabs
rather than served from here.

**Interval / Convening** — the two countdowns. INTERVAL is for breaks; CONVENING
opens a broadcast.

**Grace** — time counted past zero, in crimson, rather than stopping.

**Terminal word** — what CONVENING resolves to at zero. `TIME` by default.

**Face** — how a countdown is drawn. Five of them.

**Rehearsal** — test mode, for exercising the kit with no audience.

## Elsewhere

**Boot stage** — one of the nine steps the launch sequence performs. Named in
the NEXUS boot report.

**Harmonics** — the final boot stage: a health check of the archive.

**The Board** — the shared database behind DISPATCH. Not this machine's.

**Operator** — you. Used wherever the console means the person using it, as
opposed to a viewer.

**Item** — one entry on the DISPATCH board.

**Ruling** — settling an item as RESOLVED or DENIED, with a reason.

**Entry** — one dated thing in the CALENDAR. Also one filing in a MUSTER roll;
context separates them.

**Accent** — the interactive colour, crimson or gold. Set in REGULATION.

**Grain** — the film texture over the whole console. Adjustable to zero.
