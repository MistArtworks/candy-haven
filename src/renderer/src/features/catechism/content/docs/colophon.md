# COLOPHON

The details the website carries: where to write, call, message and follow.

## What it is

COLOPHON is the first department of **PUBLICATION**, the division for what the
public reads when nothing is live. BROADCAST is what an audience sees while a
stream is on; PUBLICATION is the standing record they can read at any hour,
which is the website and everything it carries.

A colophon is the note at the back of a book saying who made it and where they
can be found. The website's footer and its contact page are exactly that note,
so this is where it is written: once, here, rather than typed into the site.

It is one record, not a register. The website has one address, one number, one
username and one profile on each platform, so there is nothing to add or remove
except the platforms themselves.

## The fields

| Field                | What it is                                  | The rule                                                             |
| -------------------- | ------------------------------------------- | -------------------------------------------------------------------- |
| **Booking email**    | Where bookings and questions are written to | A name, an `@` and a domain                                          |
| **Phone number**     | The number, as it should read on the page   | Digits and `+ ( ) - .` only; a `+` only at the start; 7 to 15 digits |
| **Discord username** | The username people message after a booking | 2 to 32 characters: lowercase letters, numbers, `.` and `_`; no `..` |

Every field may be left empty. An empty field is the honest record of a detail
not known yet, and the website leaves out what is not set rather than printing
something plausible in its place.

A phone number is **kept as you space it**: `+1 (902) 555-0142` is stored as
typed, because how a number reads is a local custom and yours to choose. What
it dials is taken from its digits, keeping the `+`, and shown under the field
as `Dials as +19025550142` so you can see exactly what a phone will be handed.

A Discord username is refused rather than corrected. Typing `CandyHeist` is
told that usernames are lowercase; it is not quietly stored as `candyheist`,
because a record should hold what you wrote. The old `name#1234` tags are
refused with the reason, since Discord retired them.

## Profiles

The **Profiles** panel holds the artist's profile on each platform people
follow and listen on: one field per platform, never two, because the website
draws each platform behind its own mark and has nowhere to put a second.

Five are always on the page, set or not:

| Platform        | On the website                |
| --------------- | ----------------------------- |
| **Instagram**   | The navbar and the footer     |
| **Spotify**     | The navbar and the footer     |
| **Apple Music** | Kept for the website to carry |
| **SoundCloud**  | The navbar and the footer     |
| **YouTube**     | The navbar and the footer     |

YouTube here is the channel. YouTube Music is a platform of its own, below.

Every other platform is added when there is a profile to put on it. Paste the
address into **Add a platform**: the platform is read from the address, the
field says which it is, and **Add** (or Enter) puts it on the page. **Remove**
takes an added platform off again; the five above cannot be removed, only left
empty. The platforms it knows besides the five:

YouTube Music, Deezer, TIDAL, Amazon Music, Bandcamp, Beatport, Beatsource,
Traxsource, Mixcloud, Audiomack, Qobuz, Pandora, Anghami, Boomplay, JioSaavn
and Gaana.

An address must be on the platform its field is for. A SoundCloud address
pasted into Spotify's field is refused as `That address is on SoundCloud, not
Spotify`, because the website would draw it behind the wrong mark and nobody
would notice until somebody clicked it. An address on none of the platforms
above cannot be added at all: a Linktree or a press piece is not a profile.

> These are **not** your card on the roster. The card is every address you can
> be found at, kept so credits can point somewhere. These are the ones the
> website points people to. Tying the two together would put a page you added
> for a credit into the website's footer.

## Filing

The page is a draft. Typing changes nothing in the archive; the unsaved-changes
bar rises at the bottom of the console, and **File changes** writes every field
at once, adding and removing platforms included. **Discard** forgets every
unfiled edit and shows the record as it was last filed.

This is the way REGULATION files settings, and it is chosen for the same
reason. The roster's sheet saves as you stop typing, which suits a record you
are reading as much as writing. This one is built into a website, and an
address saved halfway through being typed would be published halfway through.

While anything is unfiled, picking another department on the rail nudges the
bar instead of navigating. File it or discard it first.

> The guard is on the rail, as it is for REGULATION. A keyboard chord or the
> command palette still leaves the page, and an unfiled change goes with it.

If a field is red when you file, nothing is written and the bar says so. The
archive applies the same rules again when the record arrives, so a colophon can
never hold an address that is not one, whatever writes it.

An address left in **Add a platform** is not part of the draft. It is filed
once Add has put it under its platform, and not before.

## Where it is kept

In the archive, on this machine, in the `publication_colophon` collection, as
one document. It is archive data rather than a setting, so REGULATION's export
does not carry it, and it survives a settings reset untouched.

Nothing reads it from outside yet. The **Publication** panel beside the details
says exactly that: kept here, not yet published, and when it was last filed.
Publishing the website from this console is still to come, and this is the
first record it will be built from.

A colophon filed while this page still kept a list of links is read into the
profiles: each link goes under the platform its address is on, and one on no
platform the colophon knows is left out.
