Starting a track no longer means opening the console.

## THE VESTIBULE

Launching now opens a small window before anything else, with four square
doors: **THE CONSOLE**, **NEW PROJECT**, **ARCHIVE** and **OBSERVATORY**.

Most launches are a new track, and the console is a whole operator station
standing in front of what is really two fields. So NEW PROJECT does the work
here: a name, a shelf, a colour. It makes the folder, copies your template set
into it, opens it in Ableton and stands the application down to the tray. The
console never loads at all.

The other three open it — and the last two land it already standing in that
department, because filing a set and putting a stream on are what this console
gets opened for, and arriving at NEXUS to then navigate is a step that exists
for no reason.

## Choosing the shelf

The SHELF field is a miniature of the filing tree. Click through categories and
genres the way you would in ARCHIVE; the folder you are standing in is where
the set lands, and it says so underneath. It remembers where you filed last, so
the usual case is no navigation at all.

A category is somewhere you pass through, not somewhere a project goes, and the
field says that rather than letting you find out on CREATE.

## It is already warm by the time you choose

The archive starts up behind the window rather than in front of it, so it is
usually online before you have finished reading the doors. The rail along the
bottom says where the sequence has got to, and NEW PROJECT stays shut — with
the reason under it — until the archive is connected and the department is set
up. Choosing THE CONSOLE after a clean start takes you straight in, with no
boot screen to click through.

## The details

- A set made here is a **single**. It is one row in the dossier to change later,
  and not a question worth asking before the track exists.
- **Closing the window ends the session.** It is the front door; declining both
  of the things it offered means you did not want the application open.
- The tray and a second launch both find the vestibule rather than building a
  console behind it.
- Turn the whole thing off in **REGULATION → STARTUP**. Launching then goes
  straight to the console exactly as it used to. A sign-in launch never shows
  it either way — the point of starting with the machine is that the archive
  and the overlay server are up, not that you are asked a question.

## Under it

The field behind the doors is the same plexus the NEXUS scenes are built from,
laid out as a slab rather than a sphere — a sphere is a focal object, and the
focal object here is whichever door you are reaching for.

Separately, every window in the application now loads about 167 kB less: a
single import in the calendar's constants was pulling the whole schema library
into the renderer, because every form field in the console reads the date
helpers next to it.
